Login Behavior
--------------
File: Form1.vb
Event handler:
- loginbtn_Click(sender, e) Handles loginbtn.Click

Flow:
1. Reads usertxtbox.Text and trims it into inputUsername.
2. Reads passtxtbox.Text and trims it into inputPassword.
3. Rejects empty values with a warning MessageBox.
4. Queries the Users_tbl database table using GlobalDatabase.GetTable.
5. Query columns: UserID, FullName, Role, IsActive.
6. Query parameters: @Username and @Password.
7. Rejects inactive accounts.
8. On success, reads Role and FullName.
9. Creates DashboardForm(role, fullName).
10. Shows DashboardForm and hides the login form.
11. Shows an error MessageBox for invalid credentials or database exceptions.
